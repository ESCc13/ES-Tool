## 昵称弹窗「点按钮没反应」定位与修复（用户报的 2 个问题）

- **根因**：`PCL.MyTextBox` 把 `Text` 做成了自定义依赖属性，赋值/输入时**不触发 WPF 的
  `TextChanged`** → 弹窗里 `_box.TextChanged` 里那句 `_ok.IsEnabled = ...` 永远不执行 →
  「确定」一直停在 `IsEnabled=false`（截图里是浅蓝 #B9CFEC 禁用态），点它当然一点反应都没有。
  连带「随机昵称」写 `_box.Text = "rj"` 也不会让确定亮起来。
- **修法**：`src/UI/SetNameDialog.cs` 整个重写，**不再用任何 PCL 控件**，全原生 WPF：
  `TextBox` + `Button` + 四个 `ControlTemplate`（`EsBtnPrimary` / `EsBtnSecondary` / `EsClose` /
  `EsInput`，用 `XamlReader.Parse` 解析一段 XAML 拿模板）。原生 TextBox 的 TextChanged 必定触发。
- **配色对齐主界面**（用户第二问）：标题条 #1370F3、白底、描边 #8899AA、圆角 8、
  正文 #343D4A / 灰字 #8C8C8C / 提示 #A8A8A8、主按钮 #1370F3（hover #3184F6 / press #0C5FD8 /
  disabled #B9CFEC）。跟 PclMainWindow 的 blue/text/sub 完全同一套值。
- **按钮反馈**：模板里显式写 IsMouseOver / IsPressed / IsEnabled 三态 + `Cursor=Hand`；
  另加 `PreviewMouseLeftButtonUp` 兜底（`Finish()` 里有 `_done` 幂等锁，双触发也只关一次）。
- **验证（可复用的无头鼠标测试）**：`_tools/test_namedlg.py` —— ctypes 起进程、
  `EnumWindows` 找「设置昵称」、`ClientToScreen` 把 440x274 逻辑坐标换算成物理坐标、
  `mouse_event` 真点。结果：随机昵称→确定 返回 `rj` 并关闭；先跳过 返回 `<null>` 并关闭；
  空输入点确定 不关闭（符合预期）。
  - 坑：`keybd_event` 打字会被中文输入法吃掉（变成组字未上屏，Text 仍为空），
    所以测按钮不要靠键盘打字，用「随机昵称」这种程序化写文本的路径。
- **截图验证链（本机没 Pillow）**：`_tools/shot.py`（BitBlt 桌面区域 → 手写 BMP）+
  `_tools/bmp2png.py`（zlib 手写 PNG 编码）。GetDIBits 实际给的是自下而上，转换时要 flip。
